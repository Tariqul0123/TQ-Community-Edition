# Security Policy

This reconstructed community release was published under an owner-approved exception. It is not a security certification, and three pre-publication gates were waived as documented in `OWNER-APPROVED-EXCEPTION.md`.

- Do not post secrets, personal data, production hostnames, or exploit details in public issues.
- Report suspected vulnerabilities privately to the repository maintainer using GitHub's private vulnerability reporting if enabled.
- Rotate any credential that may have been exposed; removing it from a commit is not sufficient.
- Do not expose Local AI inference directly to the public internet.
- Keep production TQ, its database, credentials, and authoritative memory separate from this community repository.
- No security response-time SLA is currently promised.

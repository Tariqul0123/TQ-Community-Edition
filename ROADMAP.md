# Roadmap

## Near term
- Establish safe provider interfaces and department-based routing examples.
- Improve tests and documentation.
- Define a synthetic-data demo profile and explicit isolation checks.
- Strengthen CI and add dedicated secret scanning when review capacity is available.

## Later
- Add provider health/latency/quota-aware routing.
- Add observability without logging secrets.
- Add documented approval workflows for high-impact actions.
- Evaluate Local AI capabilities with benchmarks before expanding responsibilities.

Roadmap items are proposals, not commitments or implemented features.
